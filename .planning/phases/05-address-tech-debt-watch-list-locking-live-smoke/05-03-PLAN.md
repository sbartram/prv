- **Env var and placement (Claude's discretion):** `PRV_LIVE=1`; `internal/github/live_test.go` in the external package `github_test`, so it uses only the exported API, like a real caller.

- **The yellow warning check (test 2):** a live low budget needs about 4,000 points spent, so the check judges the shared yellow on the failure marker instead (wording is Claude's discretion under D-16).
