## Phase Goal

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| api.github.com → prv | The PR `url` field that `o` opens comes from the API |
| user config file → prv | The config path and warnings are rendered in the overlay |
| prv → OS browser launcher | `o` hands a URL to go-gh's browser, which runs the user's configured launcher |

| T-02-16 | Spoofing / Elevation of privilege | `o` → safeURL → openCmd | high | mitigate | net/url parse with exact scheme https, host github.com (case-insensitive), no port, no user info; only the rebuilt u.String() is opened; TestSafeURL covers github.com.evil.com, github.com@evil.com, http, port, subdomain, javascript:, spaces and control characters |
