# Phase 02 Plan 02: r refreshes at once and never overlaps, the header says when the data was last updated, and the selection stays on the same PR

## Phase Goal

**As a** developer who keeps prv open in a terminal pane all day, **I want to** have it refresh itself, stay inside the API rate limit, narrow the list and jump to a PR on github.com, **so that** I can trust that what I see is current without opening a browser.

<objective>
- Task 1: `r` refreshes from every screen and merges with a running refresh; one keymap matches every key; a real `tea.Program` proves under `-race` that refreshes never overlap (RFSH-02, D-17 keymap source).
- Task 2: the header shows `updated HH:MM:SS` and a spinner while a refresh runs (RFSH-03, D-05).
- Task 3: the selected PR stays selected across refreshes even when it moves, with a nearest-neighbour fallback when it leaves the list (RFSH-06, D-03).

Purpose: success criterion 1 (`r`, last-update time), the "no overlapping refreshes" part of criterion 2, and the "selected PR stays selected" part of criterion 3. Roadmap pitfalls: coalesced `r`, generation counter, selection tracked by PR ref with a nearest-neighbour fallback.
Output: `internal/ui/keys.go`, `r` handling and spinner in `internal/ui/model.go`, `clock()` and the header in `internal/ui/view.go`, `rebuild()` with selection by ref, `internal/ui/selection_test.go`.
</objective>

<assumption_delta_decision>
- Detector: `assumption-delta scan 2` fired a pluralization signal on "nearest-neighbour fallback" (selection).
- Primary noun now: `domain.Ref` (owner/repo#n) is the identity of the selection. The row index (`cursor`) is demoted to a value derived from `selected` on every rebuild.
- Decision: promote. The Phase 1 model kept only `cursor` (an index); this plan makes `selected domain.Ref` the source of truth and recomputes `cursor` from it, instead of keeping both as independent state.
- Invariant test (accepted): TestSelectionInvariant — after any sequence of refresh results and j/k presses, whenever the selected ref is in the visible rows, `rows[cursor].Ref == selected`.
</assumption_delta_decision>
