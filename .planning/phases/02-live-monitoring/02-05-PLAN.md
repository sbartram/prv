# Phase 02 Plan 05: Settings come from config.toml, "?" explains every key and badge, and "o" opens the selected PR on github.com

## Phase Goal

**As a** developer who keeps prv open in a terminal pane all day, **I want to** have it refresh itself, stay inside the API rate limit, narrow the list and jump to a PR on github.com, **so that** I can trust that what I see is current without opening a browser.

<objective>
- Task 1: config.toml is complete — closed_days and show join refresh_interval, bad values stop prv with the file and line (D-15), unknown keys warn once, and the hidden --closed-days flag beats the config inside a shared 1..365 bound (D-14, D-16, WR-01). The closed window reaches the search and the filter (FILT-02).
- Task 2: "?" shows a full-screen help overlay built from the same keymap as the footer, with the badge legend, the effective settings and the API budget (D-17, NAV-03).
- Task 3: "o" opens the selected PR on github.com through go-gh's browser, only for exact https://github.com URLs, with a footer message when it cannot (NAV-02).

Purpose: success criteria 1 (config file, defaults), 4 (configured closed window) and 5 (o and ?).
Output: complete `internal/config`, flag precedence in `cmd/prv`, `internal/ui/help.go`, `internal/ui/open.go`, `browserOpener`.
</objective>
