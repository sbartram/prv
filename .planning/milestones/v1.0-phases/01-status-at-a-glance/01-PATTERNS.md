### `internal/domain/pr.go` (01-01 Task 1)

Define `State`, `Review` and `CI` as typed constants. `ReviewNone` and `CINone` are the zero values, and `CIUnknown` is a separate value. `ParseState` maps "OPEN", "MERGED" and "CLOSED", and maps every other string to `StateUnknown`. `DefaultClosedDays = 14` is the only default for the closed window.

### `internal/domain/list.go` (01-02 Task 1)
`list.go` holds the code that RESEARCH puts in `sort.go`. `Sort` orders by state rank (OPEN=0, MERGED=1, CLOSED=2, unknown=3), then `UpdatedAt` descending, then repo ascending, then number ascending as an int (lines 361, 302). `InWindow(pr, now, closedDays)` keeps OPEN and unknown-state PRs. It keeps MERGED/CLOSED only when `closedAt >= now - closedDays*24h` (the boundary is inclusive). `now` is a parameter. The injected clock is `github.Options.Now`.

### `internal/github/client.go` (01-01 Tasks 1-2, 01-02 Tasks 1-2)
`client.go` holds the code that RESEARCH splits into `client.go`, `query.go`, `wire.go` and `map.go`: `Options`, `NewClient`, `Fetch` with the paging loop, `const discoveryQuery`, `BuildSearch`, the unexported wire structs and the mapper.
```go
c, err := api.NewGraphQLClient(api.ClientOptions{
	Host: "github.com", AuthToken: opts.Token, Timeout: 20 * time.Second, LogIgnoreEnv: true, Transport: opts.Transport,
})
err = c.DoWithContext(ctx, discoveryQuery, vars, &out) // vars: {"q": q}, plus "after" from page 2
var ge *api.GraphQLError; var he *api.HTTPError
switch {
case errors.As(err, &ge): // out already populated; keep data, set Warnings
case errors.As(err, &he): // he.StatusCode
case err != nil:          // network, timeout, cancelled
}
```
- The query text comes from `01-SPIKE.md` "The proven Phase 1 query". It must use `type: ISSUE_ADVANCED` (TestEndToEndFixture asserts this).
- The search string is `is:pr (author:@me OR assignee:@me) (is:open OR closed:>=DATE) sort:updated-desc`, with `DATE = now.UTC().AddDate(0, 0, -(closedDays+1))`. Do not add an archive filter. Open PRs in archived repositories must stay listed. The RESEARCH and SPIKE strings include one, but 01-01-PLAN.md is authoritative.
- Pass the search string as a GraphQL variable, never by string concatenation into the query.
- Use `first: 100` and `maxPages = 5`. Set `Truncated` if more pages remain. This is the 500-result cap that the user accepted in 01-CONTEXT.md "Plan-time decisions".
- Request `viewer{login}` and `rateLimit{cost remaining resetAt}`.
- Wire structs: copy lines 484-504 with pointer element types. 01-01 uses `time.Time`, not `string`, for the timestamp fields.
- Mapper: skip nil nodes and any node with `__typename != "PullRequest"`. Dedupe by `id` (01-02). A nil author becomes `ghost`. Use `latestOpinionatedReviews` only, never `latestReviews`. Call `domain.Clean` on the title, author login, repo name and viewer login.

### `internal/github/errors.go` (01-02 Task 2)
Follow Pattern 4 (lines 308-313). Make a typed `*Error` with `Kind`, `Hint()` and an unexported `classify(err)`. The exact hint strings are in 01-02-PLAN.md Task 2 step 1:
- 401 (`KindAuth`): run `gh auth login`. If GH_TOKEN or GITHUB_TOKEN is set, it overrides the gh login: fix or unset it.
- 403/429 (`KindForbidden`): rate limit or SSO.
- 5xx (`KindServer`): retry.
- Network or deadline (`KindNetwork`): check the connection.
- GraphQL error with no data: `KindGraphQL`. Anything else: `KindUnknown`.

API error messages go through `domain.Clean`. No error text may contain the token.

## Shared Patterns

### Token and log hygiene
**Apply to:** `cmd/prv/main.go`, `internal/github/client.go`, `internal/github/errors.go` and all tests. `LogIgnoreEnv: true`. No `fmt.Println` or `log` output while the TUI runs. Errors name the token source, never the value.

### Remote-string sanitising
**Apply to:** the mapper in `internal/github/client.go` (once, at the seam: title, author, repo, viewer) and `internal/github/errors.go` (API error messages and partial-data warnings). Use `domain.Clean`.

### Pure Update/View, I/O only in tea.Cmd
**Apply to:** all `internal/ui` code (`model.go`, `view.go`, `styles.go`, `layout.go`). Bubble Tea v2 APIs only, with `charm.land/*/v2` import paths.

### Total enum mappings
**Apply to:** `internal/domain/pr.go` (`ParseState`), `internal/domain/status.go` (`DeriveReview`, `ClassifyRollup`) and the mapper in `internal/github/client.go`. An unknown value maps to a safe "unknown" or "none", never to a positive state.
