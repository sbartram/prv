# Phase 01 Plan 03: Readable rows — status at a glance, in any pane size

## Phase Goal

**As a** prv user who watches my own GitHub pull requests, **I want to** run `prv` and see, from live GitHub data, every PR I authored or am assigned to with its state, review status and CI badge, **so that** I can tell which are approved, blocked or failing CI without opening a browser.

<objective>
Make the list readable at a glance. Task 1: badges get ANSI-16 colours, drafts and merged or closed rows are dimmed, and the selection is unmistakable. Task 2: the list fits the pane (explicit column widths with TITLE truncated first, cell-width-safe), long lists scroll with the cursor, and golden snapshots lock every screen at the standard sizes.

Purpose: D-01, D-02, D-04, D-05, D-07 and the "glance" part of the core value; NAV-01 for lists longer than the screen.
Output: `internal/ui/styles.go`, `internal/ui/layout.go`, golden tests and files.
</objective>
