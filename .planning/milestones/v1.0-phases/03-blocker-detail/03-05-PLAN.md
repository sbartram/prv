# Phase 03 Plan 05: Each row shows who is reviewing and whether the PR can merge

## Phase Goal

**As a** prv user watching my pull requests, **I want to** see without leaving the terminal who and what is holding each PR up (which reviewers, which failing check, and whether it can merge), **so that** at a glance I can tell which watched PRs are approved, blocked, or failing CI.

<objective>
- Task 1: a MERGE column (mergeable / blocked / behind / conflicts / –) in every row, in the D-13 drop order and in the compact glyphs (D-05, D-07, D-13).
- Task 2: a REVIEWERS column (`✗bob …carol ✓alice`) with `+N`, the viewer as `me` and hidden teams, collapsing to a count before it drops (D-05, D-06, D-13).

Purpose: success criterion 1 ("each row shows which reviewers approved, which requested changes, and which are still pending, plus merge-readiness"), and the new columns keep success criterion 4 for the list. The data comes from plan 03-04 (`PR.Merge`, `PR.Reviewers`); the layout engine comes from plan 03-03 (`layoutColumns`, `dropSteps`, compact rows).
Output: MERGE and REVIEWERS columns, `mergeStyle`, `reviewersCell`, `reviewersCount`, help legend lines, regenerated goldens.
</objective>
