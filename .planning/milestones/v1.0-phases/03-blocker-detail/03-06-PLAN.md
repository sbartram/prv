# Phase 03 Plan 06: One query brings a PR's every check and every reviewer, counted without re-runs

## Phase Goal

**As a** prv user watching my pull requests, **I want to** see without leaving the terminal who and what is holding each PR up (which reviewers, which failing check, and whether it can merge), **so that** at a glance I can tell which watched PRs are approved, blocked, or failing CI.

<objective>
- Task 1: `FetchDetail(ctx, id)` returns one PR's de-duplicated, sorted checks, its reviewers (with commented and dismissed ones) and counts, from one Detail query (D-01, D-03, D-08, D-10, DETL-01, DETL-02).
- Task 2: PRs with more than 100 check runs are paged up to 5 pages; past that cap the counts stay de-duplicated and the result says how many runs were read (D-03 at any size, D-08).

Purpose: the data half of success criterion 3 ("a detail view that lists every check/job with its status, failing first, and every reviewer with their review state"). Plan 03-07 draws it; plan 03-08 refreshes it while the view is open.
Output: `domain.Detail` and friends, `detailQuery`, `FetchDetail` with paging, the Detail route in the github fixture transport, detail fixtures and tests.
</objective>

## Flagged assumptions (carried, not silently dropped)

- D-08 says the summary is "built from the counts, so it is correct past 100 contexts". GitHub's per-state counts include superseded runs (RESEARCH F1), and D-03 requires de-duplicated counts, so "the counts" are read as the de-duplicated counts (the same reading the user approved for '+N' in revised D-02). Paging to 5 pages keeps the summary exact up to 500 check runs. Past 500 the counts cover the runs read, and plan 03-07 shows "read N of M runs". This keeps D-03 at every size; no user decision is changed.
- A check line shows the workflow file's base name (for example `ci.yml`), the app name when there is no workflow run, and nothing for a status context (RESEARCH "Detail query").
- Reviews and requests are capped at 50 each in the detail (the largest request count seen was 13).
