# Phase 02 Plan 08: The user can narrow the list — toggle Open/Merged/Closed and type a PR number

## Phase Goal

**As a** developer who keeps prv open in a terminal pane all day, **I want to** have it refresh itself, stay inside the API rate limit, narrow the list and jump to a PR on github.com, **so that** I can trust that what I see is current without opening a browser.

<objective>
- Task 1: keys 1/2/3 toggle state visibility; the header shows which states are on and how many PRs are hidden; when the filters hide everything a filtered-empty message says so (D-10, D-12, D-13).
- Task 2: `/` opens a digits-only prompt that narrows the list live by PR-number prefix; Enter keeps, Esc clears (D-11).

Purpose: success criterion 4 (toggle states in any combination, type a PR number). FILT-02's closed window is wired from the config in plan 02-09.
Output: `domain.StateSet`, `domain.Visible`, filter state and prompt in the model, header indicator, filtered-empty and prompt rendering, `internal/ui/filter_test.go`.
</objective>
